# ORA-CENTRAL-BACKUP
Exportação de referência criada em 11/11/2026 a partir do projeto Supabase ORA-CENTRAL.

## O que contém
- `data_snapshot.json`: snapshot dos dados acessíveis nas 14 tabelas públicas.
- `schema_inventory.md`: inventário das tabelas, campos, chaves e estado RLS resumido.
- `migrations.txt`: histórico de migrações observado no projeto.
- `restore_notes.md`: orientações para o Jarvis analisar e restaurar em um projeto separado.

## Limitações importantes
Este é um backup portátil de referência, não um dump nativo completo do PostgreSQL.
Não contém senhas, tokens, service_role keys, sessões de autenticação, segredos do projeto, arquivos internos da plataforma, nem as linhas da tabela privada `private.ora_user_access`.
O código da Edge Function e a estrutura completa do banco precisam ser revisados/recriados no projeto de destino; este pacote não cria conexão automática com a origem.

Também incluído: `edge_function_ora-sync_index.ts`, fonte da Edge Function ora-sync recuperada da origem. Antes de implantá-la em outro projeto, revisar os nomes/variáveis e configurar segredos novos no ambiente de destino.
